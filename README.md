Тема курсової роботи: Довідник «Крилаті вислови».

Мета роботи: Створення програмного продукту для зручного зберігання, пошуку та класифікації афоризмів, прислів'їв та цитат. Програма дозволить користувачу систематизувати власну колекцію висловів за авторами та категоріями, а також оцінювати їх за допомогою системи рейтингу.

Сценарій використання: Користувач запускає програму, щоб швидко знайти натхнення або потрібну цитату за ключовим словом чи автором. Він може додавати нові вислови, які почув або прочитав, присвоювати їм категорії та видаляти ті, що втратили актуальність.
